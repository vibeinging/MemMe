Search Pipeline

Four independent retrieval channels fused with Reciprocal Rank Fusion.

V

Vector Search

weight: 0.5

Query embedding → cosine similarity against all memory embeddings. Semantic understanding of intent.

Always returns results
B

BM25 Full-Text

weight: 0.3

Inverted index over purified content via DuckDB FTS. Exact keyword matching for names, dates, places.

Keyword precision
E

Entity Spreading

weight: 0.2

Aho-Corasick entity extraction (<1ms) → 2-hop graph traversal → linked memories.

Graph traversal
T

Temporal

weight: 0.15

Activated by temporal intent in query ("when", "last week", month names). Time-windowed retrieval.

Time-aware

Reciprocal Rank Fusion

score(m) = Σ wi ⁄ (k + ranki)

A memory ranked #5 in vector AND #50 in BM25 can outrank one at #1 in vector alone. Cross-signal fusion yields 10–30% improvement over single-channel retrieval.

k = 30 wvec = 0.5 wfts = 0.3 went = 0.2 wtmp = 0.15
03

Meditation

LLM-powered memory consolidation. Five phases transform raw episodes into structured knowledge.

1

Decay

Time-based importance decay applied to all existing memories. Memories below threshold auto-pruned.

importance -= decay_rate × days_since_access
2

Fact Extraction

LLM reads purified episode text and extracts atomic, self-contained facts with timestamps.

Episode "Alice and I discussed the project. She mentioned visiting Shanghai next month."
Facts
  • "Alice is involved in the project"
  • "Alice plans to visit Shanghai"
3

Reconciliation

Each fact matched against 5 nearest neighbors. LLM decides the action:

ADDNew fact, no match
UPDATERefines existing
DELETEContradicts existing
NOOPAlready known

Integer-indexed IDs prevent LLM hallucination of UUIDs.

4

Graph Extraction

Single combined LLM call extracts entities and relationships as a knowledge graph.

Alice
works_on
Project
plans_visit
Shanghai
5

Entity Linking

Aho-Corasick automaton creates bidirectional memory ↔ entity links for spreading activation.

EntityIndex::build(&entities) → extract(&memory.content) → link()
04

Forgetting Curve

FSRS-inspired power-law decay. Memories fade, but access reinforces stability.

Retention

R(t, S) = (1 + t/(c·S))−p
t — days since last access
S — stability
c = 5.0
p = 0.5

Reinforcement

S′ = S × (1 + g × (1 − R))

Accessed memories grow exponentially more stable.

Search Scoring

score = sim × (0.7·R + 0.3·imp)

70% recency/stability, 30% tagged importance.

06

Bindings & API

One Rust core, six ways to use it. Every binding gets the full engine.

Python

PyO3 + maturin. Native speed in Jupyter, FastAPI, Django.

from memme import MemoryStore
store = MemoryStore(":memory:")
Node.js

NAPI-RS. Zero-copy bindings for Express, Next.js, Electron.

const { MemoryStore } = require('memme');
const store = new MemoryStore(':memory:');
Swift

UniFFI. Native iOS/macOS integration with type-safe Swift API.

let store = try MemoryStore(
    dbPath: "memory.duckdb"
)
WebAssembly

wasm-bindgen. Run the full engine in the browser.

import init, { MemoryStore }
  from 'memme-wasm';
REST API

Axum server. Self-hosted with auth, CORS, OpenAPI.

POST /v1/memories
POST /v1/memories/search
POST /v1/recall
