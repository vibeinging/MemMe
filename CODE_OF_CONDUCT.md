# Contributor Covenant Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Please read the full text at the link above. All contributors, maintainers, and participants are expected to follow it.

## Reporting

If you experience or witness unacceptable behavior, please report it by emailing **conduct@memme.dev**.

All reports will be reviewed and investigated promptly and fairly. The project team is committed to maintaining the confidentiality of the reporter.

## Enforcement

Project maintainers who do not follow or enforce the Code of Conduct may face temporary or permanent repercussions as determined by the project leadership.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
